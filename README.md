# Exit Country Widget 🍄

Виджет для Android: флаг, страна и IP, с которых тебя видят сайты (выходная страна VPN).

- Работает на любой сети, не только на Wi-Fi.
- Опрашивает 6 HTTPS-источников параллельно, страна выбирается по большинству голосов.
- Запросы идут через активную сеть (при VPN — через туннель).
- Обновление: каждую минуту (пока экран включён), при смене сети/VPN (через 3 с), по тапу.
- Счётчик «👥 N» в виджете: сколько установок онлайн прямо сейчас. Шлётся только случайный id установки (без IP и личных данных). Сервер: `server/presence.py`, страница с числом — `http://46.8.226.24:8787/`.
- Если обновить не удалось — показывает последнее значение с пометкой «устарело».
- minSdk 26, без сторонних библиотек.

## Сборка

```
./gradlew assembleDebug   # нужен Android SDK (sdk.dir в local.properties)
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Также собирается в GitHub Actions («Build APK»).

## Установка

Установить APK → долгий тап по рабочему столу → «Виджеты → Exit Country».
В настройках батареи поставить приложению «Без ограничений».
